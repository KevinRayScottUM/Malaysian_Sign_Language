# BIM Dataset V3

The raw BIM Dataset V3 videos are not stored in this repository because the dataset is too large for normal GitHub storage.

Download the dataset here:

https://1024terabox.com/s/1vmIwg6wGUwRmZfe9UhB4qQ

After downloading, place the extracted dataset folders inside this directory:

```text
BIM Dataset V3/
  <gesture_class>/
    <video_files>.mp4
```
